# メモ編集の再構成（2026-11-26）

本文・チェック・取り消し線・罫線を同じスクロール面へ統合した。罫線は「罫線あり／なし」で切り替え、端末に表示設定だけを記憶する。切り替えだけではメモを保存しない。

## エディターの選定と構成

[CodeMirror 6](https://codemirror.net/docs/ref/) を採用。既存の本文はプレーンテキストと `☐ / ☑`、独立行の添付トークン `[[att:id|name|mime]]` なので、リッチテキストのJSONやHTMLへ移行せず扱えることを優先した。Tiptap/ProseMirror、Lexical、Quillは文書ツリー等への変換が増えるため今回は採用しない。

[公式の描画構造](https://codemirror.net/examples/styling/) に沿い、実際の本文 `.cm-content` に罫線のCSS背景を指定する。行高・背景の周期は共通の32px。取り消し線は本文の文字自体の `text-decoration`、チェックは元の1文字を表示用ウィジェットへ置換する。別のtextarea、取り消し線レイヤー、自前カーソル、スクロール位置の同期処理は廃止した。カーソルと選択はエディターの標準機構を使用する。

| ファイル | 責務 |
|---|---|
| `js/memo/editor.js` | CodeMirrorの入力・選択・チェック・Undo・貼付け・罫線表示 |
| `css/memo-editor.css` | 同じ本文面の行高・背景・取り消し線・チェック |
| `js/memo/document.js` | 既存本文と添付の非破壊の読取・編集時の組立て |
| `js/memo/repository.js` | キュー永続化失敗の復旧マーカーと再送準備 |
| `js/memo.js` | 一覧・詳細の寿命・保存・添付・共通送信キューへの接続 |
| `vendor/codemirror/` | 固定したローカルESM、依存一覧・SHA・MITライセンス |

本体はローカル配信し、入力時にCDNや外部エディターサービスへ接続しない。`build/build-memo-editor.mjs --deps <npmプロジェクト>` で再生成できる。必要なpackage.json/package-lock.jsonは `vendor/codemirror/SOURCE.json` に含む。公開時は版を更新し、`version.json` に新JS/CSSとvendor runtimeを含める。

## 既存データを保持する条件

- 開いて戻るだけ、タイトルだけを変える場合は、本文のCRLF・末尾空白・末尾改行・添付行を元のまま保持する。読取時の一括変換や再保存を行わない。
- 本文の編集時も空白・空行・未知記法を削らず、チェック状態・添付の参照・未知メタデータを保持する。改行は編集時だけLFへ統一する。
- 添付形式そのものの独立行を新たに本文として入力した場合は、既存形式では区別できないため保存を拒否し、入力画面を残す。勝手に添付へ変換しない。
- 700msの自動保存、詳細を閉じる直前、非表示になる直前に、開いているメモIDへ保存する。ローカル書込や本文組立ての失敗時は画面移動を止めて入力を保持する。
- メモの保存・削除・ピン・アーカイブ・並べ替えは共通outboxへ先に記録し、`sync.flushAll`だけで送る。古い保存応答で新しいローカル本文を置換しない。
- localStorage本文保存後、IndexedDBへのキュー追加だけが失敗しても、`sth_v3_memo_recovery` のID・操作種別・tokenで再起動後まで保護する。本文の複製は作らない。再送には最新の既存ローカル本文を使い、破損した復旧情報は空扱いにせず取得・更新を止める。
- 取得の開始後に編集・削除したメモ、送信待ち、復旧待ち、現在開いているメモには古いGET結果を適用しない。遅れて終わる添付も、開き直した同じメモの最新本文へ追加する。
- 既存の保存先、APIの本文形式、localStorageの既存キー、スキーマ4、IndexedDBのDB/版、添付キャッシュは変更・削除しない。GAS変更はない。

## 検証

すべて合成データ、localhost、独立ブラウザで実施し、本番API・実記録・普段のブラウザへアクセスしない。

変更前に、メモを開いて戻るだけでCRLF・空白等の本文が75文字から64文字へ変わり保存される問題を再現した。ユーザー報告の線だけが固定される現象そのものは旧版のChrome/WebKitでは再現せず、実iPhoneでの再現成功とは扱わない。

変更後はChromeとMobile Safari UAのWebKitで、長い日本語・絵文字・折返し、32pxの行高と罫線位相、取り消し線のスクロール追従、罫線ON/OFF、チェック/Undo/改行、合成IMEイベント、貼付け、無編集での原文保持、添付、オフライン、保存失敗、遅延応答、削除後の復活防止を検証する。合成IMEイベントは実iPhoneの日本語入力確認の代わりにはならない。

実行方法と最終件数は [tests/README.md](../tests/README.md) を参照。公開前に承認を得る。Simulator、ホーム画面PWA、実iPhoneは別の確認範囲として記録する。
