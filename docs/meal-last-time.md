# 前日の最終食事の自動反映

公開候補版 `20261125-000949`。本番はまだ反映していない。

2026-11-24。習慣タブの右上「更新」を押したときだけ、表示している日の前日分の食事を取得し、その最大時刻を「前日の最終食事」へ反映する。

- 朝・昼・夕・間食・夜食の有効な時刻を比較する。0時も扱い、月・年をまたいでも前日を取得する。
- アプリの起動・再読み込み、タブを開く操作、日付切り替え、他タブの更新ではこの自動反映を実行しない。「全体更新」の追加は本人が不要と訂正した。
- 時刻が未入力・すべて不正・食事取得失敗の場合は、既存の最終食事時刻を消さない。食事取得だけが失敗しても、通常の習慣データの取得は反映する。
- 更新開始後に確定した手入力、入力中の欄、日付・タブ切り替え、送信待ち、取得後の食事編集を保護する。更新前に保存済みの最終食事時刻は、有効な食事時刻があるときは自動値へ更新する。
- 対応する時刻項目 `lastMeal` が削除済み、または時刻以外の種類なら自動保存しない。
- 書き込みは対象日の `lastMeal` 1項目のPATCHのみ。既存の永続キューを使用し、他の習慣値・食事記録・未知の値を変更しない。同じ値なら重複保存しない。
- 既存の月別食事取得・習慣保存APIを使う。GAS・シート構造・キャッシュschema・IndexedDB版の変更は不要。

実装は `js/habit.js` の手動更新経路と、時刻比較だけを担当する `js/meal-time.js`。
