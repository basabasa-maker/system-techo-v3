# iOSショートカット「システム手帳に登録」セットアップ手順

Sprint 4 で追加した「共有シート連携」を iPhone / iPad から使うための初回セットアップ手順です。
一度作ればずっと使えます。所要時間 10〜15 分。

## できること

Safari（またはTwitter、Chrome等）で気になるページを見つけたとき、
右下 or 上の「共有ボタン（□から上矢印のアイコン）」を押して「システム手帳に登録」をタップすると、
システム手帳の Memo タブに「あとで読む」エントリとして自動で保存されます。

- タイトル: ページのタイトル（自動取得）
- 本文: URL
- 種別: `read_later`（あとで読む）
- タグ: `ios_share`

保存先: Google Sheets `memo` シート → システム手帳v3 PWA の Memoタブに即時反映。

## 事前確認（作業者向け・任意）

管理PCから以下の curl で動作テストが可能です（バサバサは実行不要）。

```
curl -X POST -H "Content-Type: text/plain;charset=utf-8" \
  -d '{"type":"share_add","url":"https://www.example.com/","source":"ios_share"}' \
  "https://script.google.com/macros/s/AKfycbwSm0NCuVXkLU0CErNYn8EXR8spop6D5Fycv7JiFAAL2vipQ3PB_yBUEzw0a-zPTDDw/exec"
```

想定レスポンス:
```
{"ok":true,"data":{"id":"xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx","title":"Example Domain","url":"https://www.example.com/"}}
```

## iPhone でのショートカット作成手順

### 1. ショートカットアプリを開く

- ホーム画面で「ショートカット」アプリ（紫と青のひし形アイコン）を開きます
- アプリが見つからない場合は App Store から「ショートカット」で検索してインストール

### 2. 新しいショートカットを作成

1. 画面下のタブ「マイショートカット」をタップ
2. 右上の「＋」（プラス）ボタンをタップ
3. 「新規ショートカット」という名前で空のショートカットが開きます

### 3. アクション①「ショートカットの入力を取得」を追加

1. 画面中央 or 下部の「アクションを追加」をタップ
2. 検索欄に「入力」と入力
3. 「ショートカットの入力を取得」を選ぶ
   - ※見つからない場合は「共有シートを受け付ける」でも可
4. 受け付ける種類の設定は **後述のステップ7で一括設定** するため、ここではデフォルト状態のまま進めてOK

### 4. アクション②「テキスト」を追加（送信用JSONを作る）

1. 「アクションを追加」をタップ
2. 検索欄に「テキスト」と入力
3. 「テキスト」アクションを選ぶ
4. テキスト欄に次の内容を入力:

```
{"type":"share_add","url":"URL_PLACEHOLDER","source":"ios_share"}
```

5. 上記の `URL_PLACEHOLDER` の部分を削除して、その位置にカーソルを置きます
6. キーボード上部のサジェスト欄から「ショートカットの入力」（マジック変数）をタップして挿入
   - うまく挿入できない場合: テキスト欄を長押し → 「変数を選択」 → 「ショートカットの入力」
7. 最終的にテキスト欄は以下のように見えればOKです（`《ショートカットの入力》` は iOS 上では**青い変数バブル**として表示されます）:

```
{"type":"share_add","url":"《ショートカットの入力》","source":"ios_share"}
```

**重要**: 変数バブルの**前後に半角ダブルクォート `"` を手入力で追加**してください。JSON仕様上、URLは文字列なのでクォートが必須です。これを忘れるとサーバー側でエラーになります。

### 5. アクション③「URLの内容を取得」を追加

1. 「アクションを追加」をタップ
2. 検索欄に「URLの内容を取得」と入力
3. 「URLの内容を取得」アクションを選ぶ
4. アクション右側の「▸」または「表示を増やす」をタップして詳細設定を開く
5. 以下を設定:
   - **URL**: 次のアドレスを貼り付け
     ```
     https://script.google.com/macros/s/AKfycbwSm0NCuVXkLU0CErNYn8EXR8spop6D5Fycv7JiFAAL2vipQ3PB_yBUEzw0a-zPTDDw/exec
     ```
   - **方法（Method）**: 「POST」を選択
   - **ヘッダ（Headers）**: 「＋」で1件追加
     - キー: `Content-Type`
     - 値: `text/plain;charset=utf-8`
   - **本文を要求（Request Body）**: 「ファイル」→「テキスト」に変更
     - 本文欄をタップし、直前のアクション「テキスト」の出力（マジック変数）を挿入
     - ※「テキスト」というバブルが表示されればOK

### 6. アクション④「通知を表示」を追加

1. 「アクションを追加」をタップ
2. 検索欄に「通知」と入力
3. 「通知を表示」アクションを選ぶ
4. タイトル欄に「システム手帳に登録しました」と入力
5. 本文欄は空のままでOK（または直前のアクションの出力を挿入してレスポンス確認）

### 7. ショートカットの名前と共有シート設定

1. 画面上部の「新規ショートカット」というタイトル部分をタップ
2. 「名称変更」を選び、名前を「システム手帳に登録」に変更
3. 同じ画面で「詳細」または設定アイコン（ⓘ や iマーク）をタップ
4. 以下をオンに切り替え:
   - **共有シートに表示**: ON
   - **受け付ける種類**: 「URL」のみチェック（Web ページも含まれる）
5. 「完了」または「×」でショートカット編集を終了

### 8. 動作テスト

1. Safari を開き、適当なWebページ（例: `https://www.apple.com/jp/`）を開く
2. 下部中央（or 上部右）の共有ボタン（□と上向き矢印）をタップ
3. スクロールして「システム手帳に登録」を見つけてタップ
   - 見つからない場合: 共有シートを下までスクロール → 「アクションを編集」 → 「システム手帳に登録」を有効化
4. 「システム手帳に登録しました」という通知が表示されれば成功
5. システム手帳v3 PWA を開き、Memoタブで該当ページが「あとで読む」として登録されていることを確認
   - URL: https://basabasa-maker.github.io/system-techo-v3/

## うまくいかない時のチェックリスト

| 症状 | 対処 |
| --- | --- |
| 共有シートにショートカットが出ない | 共有シートを下までスクロール→「アクションを編集」→対象をON |
| 通知は出るが手帳に登録されない | JSON本文のダブルクォート `"` がURL変数の前後にあるか確認 |
| エラー通知が出る | ショートカットアプリを開き、該当アクションをタップして設定を確認 |
| 複数回タップしてしまった | 同じURLでも別エントリとして登録される（重複チェックなし）。Memoタブで手動削除可能 |

---

## 変更する場合

- GAS URL が変わったら: アクション③「URLの内容を取得」のURL欄を差し替え
- タグを変えたい: アクション②のテキスト中の `ios_share` を好きな文字列に変更

## 参考情報（開発者向け）

- エンドポイント: `POST /exec` (type=share_add)
- スコープ: `https://www.googleapis.com/auth/spreadsheets` + `https://www.googleapis.com/auth/script.external_request`
- 保存先シート: `memo`（Google Sheets `1pENt1pTtF9A3CV-VY0VnP8VlbNM5mPZW9tSAtE8YKXs`）
- 保存時の entry_type: `read_later`
- タイトル自動取得: `og:title` → `<title>` の順で取得。失敗時は URL を title として保存
- body 列: URL をそのまま格納
