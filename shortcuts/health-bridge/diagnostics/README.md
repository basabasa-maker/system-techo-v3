# 歩数の取得元確認（2026-11-27 R2）

歩数の不一致を調べる、キー不要・保存送信なしの診断用Shortcut。通常の連携Shortcutや手帳の設定を置き換えない。不一致の修正完了版ではない。

## iPhoneで使う

1. [診断用ZIP](steps-source-check.zip?_app_update=steps-source-check-r2)をダウンロードする。
2. 「ファイル」→「ダウンロード」で `steps-source-check.zip` をタップして展開し、中の `歩数の取得元確認.shortcut` を開く。
3. 「ショートカットを追加」を押す。キー入力はない。追加済みの `歩数の取得元確認` の再生ボタンを押す。必要な場合は本人が歩数の読み取りを許可する。
4. 「歩数ソース診断／保存・送信なし」で始まる結果が出る。対象日とソース別の行を確認する。読み取りと出力はiPhone内で完結し、送信しない。

既定は実行日の端末現地日付。前日等を確認したい場合は、この診断だけを編集し、最初の空のテキストへ yyyy-MM-dd を入れる。通常Shortcut・手帳側の連携名・キーは編集しない。名前変更や旧版削除は不要。

## 内容と限界

現行のSteps日別queryと採用条件をそのまま複製し、同じ日付窓でGroupByだけを外したraw queryを追加。対象日、取得時刻とoffset、開始/終了、GroupByDay候補数/採用値、raw件数/診断用単純合計、Source表示名ごとの件数/合計を1画面で表示する。

raw合計はHealthの統合合計ではなく、正しい歩数として手帳へ保存してはいけない。同じSource表示名のサンプルは合算するため、同名機器を区別できる保証はない。登録済み旧機器があるだけで重複と断定しない。Sourceの実iPhone上の型・名前変換は未検証。

日付・数値・単位・Sourceを架空辞書へ置き換え、ネット/Health/保存アクションのない別fixtureをMacのApple Shortcuts実行器で8ケース確認。複数ソース、同名ソース、欠測、実測0、別日・単位違い除外、GroupByDay複数候補拒否、空日付fallbackが成功。初稿の空Source判定不備を実行器試験で発見し、R2のregex判定で修正した。これを実iPhoneのHealth検索成功や不一致解消の証拠とは扱わない。

公開するのは署名済みファイル1個入りZIPとキーなしsource/manifest。本人用Shortcutの書出しや個人測定値は含まない。通常の4項目連携・GAS・保存先・過去記録は変更していない。
